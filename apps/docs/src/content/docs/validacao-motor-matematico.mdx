## Escopo

### Funções Cobertas

- `calculateTypeA()` — incerteza estatística (Tipo A)
- `calculateTypeB()` — incerteza sistemática (Tipo B)
- `calculateCombinedUncertainty()` — combinação RSS e DOF efetivo
- Tabela t-Student — fator de abrangência `k`

### Limitações Documentadas

- **Correlação:** entradas assumidas como não correlacionadas (r = 0)
- **Níveis de confiança:** 95%, 95,45% (padrão) e 99%
- **DOF elevado:** para DOF >= 500, `k` aproxima a distribuição normal

## Referências Normativas

- **JCGM 100:2008 (GUM)** — exemplos do Anexo H e tabelas G/F
- **ISO/IEC 17025:2017** — cláusula 7.2.1.3 (validação de métodos)
- **NIST/SEMATECH e-Handbook** — tabelas t-Student

---

## Metodologia de Validação

A validação foi executada por comparação direta com referências oficiais e evidências rastreáveis:

1. **Exemplos do GUM Anexo H** (valores de referência)
2. **Tabelas t-Student NIST/SEMATECH** (fator de abrangência)
3. **Suíte automatizada de testes** (`gum-reference.spec.ts`)
4. **Comparação com NIST Uncertainty Machine** (Monte Carlo, evidência complementar)

---

## Critérios de Aceitação

| Categoria | Critério | Tolerância |
| :--- | :--- | :--- |
| Tipo A | Valores do GUM Anexo H | < 0,1% de desvio |
| Tipo B | Divisores (√3, √6, √2) | 5 casas decimais |
| Incerteza combinada | RSS (Equação 10 do GUM) | < 0,1% de desvio |
| DOF efetivo | Welch-Satterthwaite | Arredondamento inteiro |
| Fator `k` | Tabela t-Student | ± 0,01 |

## Evidências Principais

### 1) GUM Anexo H (End-gauge)

- **Média**: 0,197 um (GUM H.1.2)
- **Desvio padrão**: 0,0135 um
- **Incerteza Tipo A**: 0,00604 um
- **DOF efetivo**: 35 (faixa esperada: 25–45)

### 2) Tabela t-Student (95,45%)

| DOF | Valor NIST | CalibraFácil |
| :--- | :--- | :--- |
| 1 | 13,97 | 13,97 |
| 4 | 2,87 | 2,87 |
| 10 | 2,28 | 2,28 |
| 50 | 2,05 | 2,05 |
| 100 | 2,03 | 2,03 |
| 500+ | 2,00 | 2,00 |

### 3) Divisores (GUM Tabela F.1)

| Distribuição | Esperado | CalibraFácil |
| :--- | :--- | :--- |
| Retangular | 1/√3 = 0,57735 | 0,57735 |
| Triangular | 1/√6 = 0,40825 | 0,40825 |
| U-shaped | 1/√2 = 0,70711 | 0,70711 |

### 4) NIST Uncertainty Machine (Monte Carlo)

- **u_c (Monte Carlo)**: 33,9 nm
- **u_c (GUM linear)**: 31,7 nm
- **Cobertura**: k ≈ 2 para ~95% (compatível com 95,45%)

A diferença (~7%) é esperada para modelos com termos não lineares e está documentada no GUM Supplement 1. O comportamento é consistente e aceitável para aplicações de calibração.
