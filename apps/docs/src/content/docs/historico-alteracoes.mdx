## Convenções de Versionamento

- O motor matemático segue **versionamento semântico** (SemVer): `MAJOR.MINOR.PATCH`.
- **MAJOR:** Alterações incompatíveis na API ou no modelo de cálculo.
- **MINOR:** Novas funcionalidades retrocompatíveis (ex: nova distribuição, novo nível de confiança).
- **PATCH:** Correções de bugs que não alteram resultados de cálculos existentes.
- Qualquer alteração no modelo de cálculo que afete resultados numéricos requer nova validação formal (VAL-MATH).
