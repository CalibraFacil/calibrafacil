## Visão Geral

A seção **Ativos** (`/dashboard/assets`) gerencia os instrumentos e equipamentos dos clientes que são calibrados pelo laboratório. Cada ativo é vinculado a um cliente e a um tipo de ativo, com especificações técnicas personalizáveis.

## Cadastro de Ativo

<Steps>

1. **Selecionar o cliente**

   Escolha o cliente proprietário do instrumento.

2. **Selecionar o tipo de ativo**

   O tipo define quais especificações técnicas serão solicitadas (ex: "Balança Analítica" exige resolução, capacidade; "Termômetro Digital" exige faixa de medição).

3. **Identificação**

   - **Nome:** Descrição do instrumento (ex: "Balança Mettler XS205")
   - **Tag:** Identificação interna única do laboratório (ex: "BAL-001")
   - **Número de série:** Serial do fabricante
   - **Modelo:** Modelo do equipamento
   - **Fabricante:** Fabricante do equipamento

4. **Especificações técnicas**

   Campos dinâmicos gerados pelo tipo de ativo selecionado. Exemplo para uma balança:
   - Resolução: 0,01 mg
   - Capacidade: 220 g
   - Classe: II

5. **Salvar**

</Steps>

<Aside type="caution">
  O **tag** deve ser único em todo o laboratório. Use uma convenção consistente como "TIPO-NÚMERO" (ex: BAL-001, TERM-015, MIC-003).
</Aside>

## Tipos de Ativo

Os tipos de ativo definem categorias de instrumentos e suas especificações técnicas. Cada tipo possui uma **definição de campos** que determina quais informações serão coletadas.

Exemplos de tipos:

| Tipo de Ativo | Campos Típicos |
| :--- | :--- |
| Balança Analítica | Resolução, capacidade, classe |
| Termômetro Digital | Faixa de medição, resolução |
| Micrômetro | Faixa, resolução, classe de exatidão |
| Manômetro | Faixa de pressão, classe, diâmetro |

Cada campo na definição possui:
- **Chave:** Identificador interno
- **Rótulo:** Nome exibido no formulário
- **Tipo:** `text`, `number` ou `select`
- **Unidade:** Unidade de medida (para campos numéricos)
- **Obrigatório:** Se o preenchimento é mandatório

## Status do Ativo

| Status | Descrição |
| :--- | :--- |
| **ACTIVE** (Ativo) | Em uso, disponível para calibração |
| **INACTIVE** (Inativo) | Fora de uso temporariamente |
| **MAINTENANCE** (Manutenção) | Em reparo ou manutenção |
| **SCRAPPED** (Descartado) | Permanentemente fora de uso |

<Aside type="note">
  Ativos são **excluídos logicamente** (soft delete) para preservar a trilha de auditoria. Mesmo após a exclusão, os registros históricos de calibração permanecem acessíveis.
</Aside>

## Rastreamento de Calibração

O sistema mantém automaticamente:

- **Última calibração:** Atualizada quando uma OS é aprovada para este ativo
- **Próxima calibração:** Calculada com base no intervalo de calibração

Quando a data de próxima calibração se aproxima, o sistema envia notificações de **ASSET_DUE_FOR_RECALIBRATION** para os administradores.

## Filtros e Busca

A lista de ativos oferece múltiplos filtros:

| Filtro | Descrição |
| :--- | :--- |
| **Busca** | Por nome, tag ou número de série |
| **Cliente** | Lista suspensa com busca |
| **Status** | ACTIVE, INACTIVE, MAINTENANCE, SCRAPPED |

Use o botão **Limpar Filtros** para resetar todos os filtros de uma vez.
