## Abas de Configuração

Acesse em **Painel → Configurações** (`/dashboard/settings`). As configurações são organizadas em abas:

| Aba | Descrição | Quem acessa |
| :--- | :--- | :--- |
| **Perfil** | Nome, email, foto do usuário | Todos |
| **Segurança** | Senha, autenticação de dois fatores, sessões | Todos |
| **Aparência** | Tema (claro, escuro, sistema) | Todos |
| **Organização** | Nome, CNPJ, endereço, dados de acreditação | Admin, Owner |
| **Certificados** | Templates de certificado, logo, marca | Admin, Owner |
| **Assinatura** | Imagem da assinatura manuscrita | Admin, Owner |
| **Condições Ambientais** | Limites de temperatura, umidade e pressão | Admin, Owner |
| **Notificações** | Preferências de email e notificações in-app | Todos |
| **Cobrança** | Plano de assinatura, pagamentos, faturas | Owner |
| **Zona de Perigo** | Exportação de dados, exclusão da conta/organização | Owner |

## Papéis e Permissões

O sistema possui 5 papéis hierárquicos. Cada papel herda as permissões do nível inferior.

### Hierarquia

```
Owner > Admin > Technician > Member > Client User
```

### Permissões por Papel

| Recurso | Member | Technician | Admin | Owner |
| :--- | :--- | :--- | :--- | :--- |
| **Dashboard** | Visualizar | Visualizar | Visualizar | Visualizar |
| **Clientes** | Visualizar | Criar, editar | Tudo | Tudo |
| **Ativos** | Visualizar | Criar, editar | Tudo | Tudo |
| **Padrões** | Visualizar | Criar, editar, renovar | Tudo | Tudo |
| **Métodos** | Visualizar | Visualizar | Criar, editar, publicar | Tudo |
| **Serviços** | Visualizar | Visualizar | Criar, editar | Tudo |
| **Ordens de Serviço** | Visualizar | Criar, executar, submeter | Tudo + aprovar/rejeitar | Tudo |
| **Não Conformidades** | Visualizar | Criar, editar | Tudo + aprovar disposição | Tudo |
| **CAPA** | Visualizar | Criar, editar, implementar | Tudo + verificar, encerrar | Tudo |
| **Configurações** | Perfil próprio | Perfil próprio | Organização, certificados | Tudo |
| **Cobrança** | — | — | — | Tudo |
| **Membros** | — | — | Convidar, remover | Tudo |

<Aside type="caution">
  **Separação de responsabilidades (ISO 17025):** Técnicos podem executar e submeter calibrações, mas **não podem** aprovar ou rejeitar. Somente administradores e proprietários têm permissão de aprovação.
</Aside>

### Client User (Usuário do Portal)

O papel **Client User** é exclusivo do [Portal do Cliente](/portal):
- Visualiza apenas dados do próprio cliente (ativos, calibrações, certificados)
- Não tem acesso ao painel do laboratório
- Pode fazer download de certificados aprovados

## Configuração de Certificados

Na aba **Certificados**, configure a aparência dos certificados de calibração:

- **Logo do laboratório:** Imagem exibida no cabeçalho do certificado
- **Dados de acreditação:** Número de acreditação, organismo acreditador
- **Responsável técnico:** Nome que aparece no certificado

## Assinatura Digital ICP-Brasil

Na aba **Certificados**, importe o certificado digital para assinatura de PDFs:

1. Faça upload do arquivo `.p12` (certificado ICP-Brasil A1)
2. Informe a senha do certificado
3. O sistema armazena o certificado com **criptografia AES-256-GCM**
4. Defina como certificado padrão para assinatura

O certificado digital é usado na [aprovação de ordens de serviço](/guia/ordens/aprovacao) para assinar os PDFs dos certificados de calibração.

<Aside type="note">
  A senha do certificado é criptografada e nunca exibida novamente. Se precisar alterar, faça um novo upload.
</Aside>

## Assinatura Visual

Na aba **Assinatura**, faça upload da imagem da assinatura manuscrita:
- Formato: PNG com fundo transparente (recomendado)
- A imagem aparece no certificado PDF junto à assinatura digital

## Condições Ambientais

Na aba **Condições Ambientais**, configure os limites aceitáveis de temperatura, umidade e pressão para as calibrações:

- **Limites padrão:** Aplicados a todas as calibrações da organização
- **Limites por tipo de equipamento:** Exceções que sobrescrevem os limites padrão para tipos de instrumentos com requisitos específicos

Os limites configurados são validados automaticamente durante a execução das calibrações e registrados em um snapshot imutável para rastreabilidade.

Para detalhes completos sobre configuração, registro e fluxo de aprovação, consulte [Monitoramento Ambiental](/guia/monitoramento-ambiental).

## Notificações

Na aba **Notificações**, configure as preferências de entrega por tipo de evento:

| Tipo de Notificação | Canais Disponíveis |
| :--- | :--- |
| OS submetida para revisão | In-app, Email |
| OS aprovada | In-app, Email |
| OS rejeitada | In-app, Email |
| OS atribuída | In-app, Email |
| Certificado pronto | In-app, Email |
| Certificado retificado | In-app, Email |
| Ativo para recalibração | In-app, Email |
| Padrão expirando | In-app, Email |
| NC criada | In-app, Email |
| NC escalada para CAPA | In-app, Email |
| Pagamento recebido | In-app, Email |
| Pagamento falhou | In-app, Email |

Opções adicionais:
- **Notificar ações próprias:** Receber notificação das próprias ações (padrão: desligado)
- **Resumo por email:** Nenhum, diário ou semanal
