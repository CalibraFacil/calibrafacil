## Critérios de Aceitação

Os **critérios de aceitação** definem regras de aprovação ou reprovação para os resultados da calibração. Cada critério é uma expressão booleana avaliada após o cálculo de todas as fórmulas.

### Configuração

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Expressão | Sim | Expressão booleana que retorna verdadeiro (aprovado) ou falso (reprovado) |
| Mensagem | Sim | Texto exibido quando o critério **falha** |
| Severidade | Sim | `Erro (Reprova)` ou `Aviso (Apenas alerta)` |

### Severidade

| Nível | Efeito |
| :--- | :--- |
| **Erro** | Impede a aprovação da calibração. O instrumento é considerado **reprovado**. |
| **Aviso** | Exibe um alerta ao técnico, mas **não impede** a aprovação. |

### Expressões Booleanas

As expressões de critério usam os mesmos operadores e funções das fórmulas, acrescidos dos operadores de comparação:

| Operador | Descrição | Exemplo |
| :--- | :--- | :--- |
| `<` | Menor que | `erro < 0.01` |
| `>` | Maior que | `erro > 0` |
| `<=` | Menor ou igual | `abs(erro) <= tolerancia` |
| `>=` | Maior ou igual | `media >= limite_inferior` |
| `==` | Igual | `resultado == esperado` |
| `!=` | Diferente | `desvio != 0` |
| `&&` | E lógico | `erro >= -0.01 && erro <= 0.01` |
| `\|\|` | Ou lógico | `aprovado_range1 \|\| aprovado_range2` |

### Variáveis Disponíveis

As expressões de critério podem referenciar:

- **Campos de entrada** — pela chave do campo (ex: `tolerancia`)
- **Resultados de fórmulas** — pela chave de saída (ex: `erro`, `media`)
- **Variáveis de tabela** — com a mesma sintaxe das fórmulas (ex: `leituras_valor_count`)

<Aside type="tip">
  Ao adicionar um critério, o sistema exibe botões com todas as variáveis disponíveis. Clique em uma variável para inseri-la automaticamente na expressão.
</Aside>

### Exemplos Comuns

**Erro dentro da tolerância:**
```
abs(erro) <= tolerancia
```
Mensagem: "Erro excede a tolerância permitida"

**Número mínimo de leituras:**
```
leituras_valor_count >= 5
```
Mensagem: "Mínimo de 5 leituras é necessário"

**Faixa de aceitação:**
```
media >= limite_inferior && media <= limite_superior
```
Mensagem: "Valor médio fora da faixa de aceitação"

**Desvio padrão máximo:**
```
desvio <= 0.001
```
Mensagem: "Repetitividade insuficiente — desvio padrão acima do limite"

## Componentes de Incerteza Tipo B

Os **componentes de incerteza Tipo B** representam contribuições de incerteza obtidas por meios não estatísticos — como certificados de calibração de padrões, especificações do fabricante ou resolução do instrumento.

<Aside type="note">
  A incerteza **Tipo A** (desvio padrão da média) é calculada automaticamente a partir das leituras. A Tipo B deve ser configurada manualmente no método.
</Aside>

### Configuração

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Nome | Sim | Descrição do componente (ex: "Incerteza do padrão") |
| Valor | Sim | Valor numérico da incerteza |
| Distribuição | Sim | Tipo de distribuição de probabilidade |
| Fator de abrangência | Não | Fator $k$ informado no certificado (para distribuição normal) |
| Divisor | Não | Divisor personalizado (sobrescreve o padrão da distribuição) |
| Graus de liberdade | Não | $\nu$ para Welch-Satterthwaite (padrão: $\infty$) |

### Distribuições de Probabilidade

A escolha da distribuição determina o **divisor** aplicado ao valor informado para obter a incerteza padrão:

| Distribuição | Divisor | Quando usar |
| :--- | :--- | :--- |
| **Normal** | $k$ (fator de abrangência) | Certificados de calibração que informam incerteza expandida com fator $k$ |
| **Retangular** | $\sqrt{3} \approx 1{,}732$ | Especificações do fabricante, tolerâncias, resolução |
| **Triangular** | $\sqrt{6} \approx 2{,}449$ | Quando há maior probabilidade no valor central |
| **U-shaped** | $\sqrt{2} \approx 1{,}414$ | Fenômenos oscilatórios (raro em calibração) |

A incerteza padrão do componente é calculada como:

$$u_B = \frac{\text{valor}}{\text{divisor}}$$

### Como o Sistema Calcula a Incerteza Final

Após a avaliação das fórmulas, o sistema:

1. Calcula a **incerteza Tipo A** ($u_A$) automaticamente a partir das leituras repetidas:

$$u_A = \frac{s}{\sqrt{n}}$$

2. Calcula cada **incerteza Tipo B** ($u_{B,i}$) dividindo o valor pelo divisor da distribuição

3. Combina todas as contribuições via **soma em quadratura** (RSS):

$$u_c = \sqrt{u_A^2 + \sum_{i} u_{B,i}^2}$$

4. Calcula os **graus de liberdade efetivos** via Welch-Satterthwaite

5. Determina o **fator de abrangência** $k$ pela tabela t-Student (tipicamente 95,45% de confiança)

6. Calcula a **incerteza expandida**:

$$U = k \times u_c$$

Para mais detalhes sobre a metodologia, consulte [Cálculos de Incerteza](/motor-matematico).

### Exemplos Comuns de Tipo B

**Incerteza do padrão de referência:**
- Valor: 0,05 mm (incerteza expandida do certificado)
- Distribuição: Normal
- Fator de abrangência: 2 (conforme certificado)
- → $u_B = 0{,}05 / 2 = 0{,}025$ mm

**Resolução do instrumento:**
- Valor: 0,001 mm (metade da menor divisão)
- Distribuição: Retangular
- → $u_B = 0{,}001 / \sqrt{3} \approx 0{,}000577$ mm

**Especificação do fabricante:**
- Valor: 0,02 °C (tolerância máxima)
- Distribuição: Retangular
- → $u_B = 0{,}02 / \sqrt{3} \approx 0{,}01155$ °C
