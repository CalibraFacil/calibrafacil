Esta seção define os termos e símbolos utilizados na plataforma e nesta documentação. As definições estão alinhadas com o **VIM (JCGM 200:2012)** e o **GUM (JCGM 100:2008)**.

## Termos de Incerteza

| Termo | Símbolo | Definição |
| :--- | :--- | :--- |
| **Incerteza padrão** | $u(x_i)$ | Incerteza do resultado de uma medição expressa como um desvio padrão. |
| **Incerteza padrão combinada** | $u_c(y)$ | Incerteza padrão do resultado obtido a partir de várias grandezas, calculada pela raiz da soma dos quadrados (RSS). |
| **Incerteza expandida** | $U$ | Grandeza que define um intervalo em torno do resultado com o qual se espera abranger uma fração significativa da distribuição de valores. $U = k \cdot u_c$. |
| **Fator de abrangência** | $k$ | Fator numérico multiplicador da incerteza padrão combinada para obter a incerteza expandida. Determinado pela distribuição $t$-Student em função de $\nu_{\text{eff}}$ e do nível de confiança. |
| **Graus de liberdade** | $\nu$ | Número de termos independentes em uma soma de quadrados. Para Tipo A: $\nu = n - 1$. |
| **Graus de liberdade efetivos** | $\nu_{\text{eff}}$ | Graus de liberdade da incerteza combinada, calculados pela fórmula de Welch-Satterthwaite. |

## Tipos de Avaliação

| Termo | Definição |
| :--- | :--- |
| **Avaliação Tipo A** | Avaliação da incerteza pela análise estatística de uma série de observações. Baseada no desvio padrão experimental da média: $u_A = s / \sqrt{n}$. |
| **Avaliação Tipo B** | Avaliação da incerteza por meios não estatísticos — certificados de calibração, especificações do fabricante, resolução do instrumento, experiência prévia. |

## Distribuições de Probabilidade

| Distribuição | Divisor | Descrição |
| :--- | :--- | :--- |
| **Normal** | $k$ (fator de abrangência) | Utilizada quando a incerteza é informada como incerteza expandida com fator $k$ conhecido. |
| **Retangular** | $\sqrt{3}$ | Todos os valores dentro do intervalo são igualmente prováveis. Típica para resolução e especificações. |
| **Triangular** | $\sqrt{6}$ | Valores centrais são mais prováveis que os extremos. |
| **U-shaped** | $\sqrt{2}$ | Valores nos extremos são mais prováveis. Típica para histerese e variações cíclicas. |
