## Visão Geral

O **Painel de Controle** (`/dashboard`) é a página inicial após o login. Ele apresenta os principais indicadores da operação do laboratório em tempo real.

## Cartões de Indicadores (KPIs)

| Indicador | O que mostra | Interpretação |
| :--- | :--- | :--- |
| **Calibrações Pendentes** | Quantidade de OS em **Rascunho** ou **Em Execução** | Trabalho em andamento — alto volume pode indicar gargalo |
| **Aprovadas no Mês** | OS aprovadas no mês corrente | Produtividade mensal do laboratório |
| **Padrões a Vencer** | Padrões de referência próximos do vencimento | Ação necessária — renovar antes que expirem |
| **Taxa de Aprovação** | Percentual de OS aprovadas vs. total avaliadas | Qualidade do trabalho — taxas baixas indicam necessidade de treinamento |
| **Serviços Atrasados** | OS que ultrapassaram a data de vencimento | Atenção imediata necessária |

## Gráfico de Tendência

O gráfico de linha mostra a evolução das calibrações ao longo do tempo, permitindo identificar sazonalidade e tendências de demanda.

## Tabela de Trabalhos Recentes

Lista as OS mais recentes com:
- Número da OS
- Status atual (com badge colorido)
- Cliente e instrumento
- Técnico atribuído
- Data de vencimento

Clique em qualquer linha para navegar diretamente à OS.

## Ações Rápidas

- **Nova Ordem de Serviço** — Atalho para criar uma OS
- **Atualizar** — Recarrega os dados do painel

<Aside type="note">
  Os dados do painel são atualizados automaticamente a cada 60 segundos. Use o botão de atualizar para forçar um recarregamento imediato.
</Aside>
