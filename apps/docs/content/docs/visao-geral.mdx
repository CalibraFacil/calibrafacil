## Fluxo de Trabalho Principal

O fluxo típico de uma calibração no CalibraFácil segue estas etapas:

```
Recebimento     Execução da       Revisão e        Certificado
do instrumento → calibração      → aprovação      → digital
(Ordem de        (Medições +       (Responsável     (PDF + assinatura
 Serviço)         incerteza)        técnico)         ICP-Brasil)
```

1. **Recebimento:** O instrumento do cliente é recebido e uma ordem de serviço é criada com os dados do cliente, instrumento e serviço solicitado.
2. **Execução:** O técnico seleciona o método de calibração, registra as leituras e o sistema calcula automaticamente os resultados e a incerteza de medição conforme o GUM.
3. **Revisão:** O responsável técnico revisa os dados, resultados e critérios de aceitação. A plataforma garante que o técnico executor não pode aprovar a própria calibração.
4. **Certificado:** Após a aprovação, o certificado de calibração é gerado automaticamente em PDF, com opção de assinatura digital ICP-Brasil e verificação pública via QR code.

## Cálculos de Incerteza

O CalibraFácil realiza cálculos de incerteza de medição em conformidade com o **GUM (JCGM 100:2008)**:

- **Tipo A** — avaliação estatística a partir de séries de leituras
- **Tipo B** — contribuições de certificados de padrões, resolução e especificações
- **Incerteza combinada** — soma em quadratura (RSS) de todas as contribuições
- **Incerteza expandida** — com fator de abrangência $k$ determinado pela tabela t-Student

Os cálculos são realizados automaticamente durante a execução da calibração. Para mais detalhes, consulte [Cálculos de Incerteza](/incerteza/motor-matematico).

## Conformidade ISO/IEC 17025

A plataforma foi projetada para apoiar laboratórios na conformidade com a **ISO/IEC 17025:2017**:

- **Rastreabilidade** de cada medição e cálculo realizado
- **Separação de responsabilidades** entre execução e aprovação
- **Gestão de competência do pessoal** com workflow, evidências de treinamento e validade (cláusula 6.2.3)
- **Gestão de não conformidades** com fluxos NC e CAPA
- **Controle de validade** de padrões de referência
- **Trilha de auditoria** completa em todas as operações
- **Escopo multiunidade** para laboratórios com mais de uma unidade
- **Autenticação corporativa (SSO)** para times maiores
- **Integrações externas** via API e conectores dedicados

Para o mapeamento detalhado de cláusulas, consulte [Conformidade ISO 17025](/conceitos/iso-17025).
