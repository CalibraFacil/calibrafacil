## O Que é uma CAPA

Uma **Ação Corretiva e Preventiva (CAPA)** é uma abordagem sistemática para identificar, analisar e prevenir a recorrência de problemas de qualidade. O registro e tratamento de CAPAs atende à **ISO/IEC 17025:2017, cláusula 8.7** (Ações corretivas) e, no aspecto preventivo, à cláusula 8.5 (Ações para abordar riscos e oportunidades).

Acesse em **Painel → Qualidade → Ações Corretivas** (`/dashboard/capa`).

## Painel Resumo

| Indicador | Descrição |
| :--- | :--- |
| **Abertas** | CAPAs em status **Aberta** |
| **Investigação** | CAPAs com análise de causa raiz em andamento |
| **Implementação** | Plano de ação em execução |
| **Atrasadas** | CAPAs que ultrapassaram a data limite |
| **Taxa de Eficácia** | Percentual de CAPAs com eficácia confirmada |
| **Encerradas** | Total de CAPAs concluídas |

## Registro de CAPA

<Steps>

1. **Informações básicas**

   - **Título:** Descrição resumida do problema
   - **Descrição:** Detalhamento completo da situação
   - **Data de detecção**

2. **Origem**

   | Origem | Descrição |
   | :--- | :--- |
   | **Detecção de NC** | Escalada a partir de uma não conformidade |
   | **Auditoria interna** | Identificada em auditoria interna |
   | **Auditoria externa** | Identificada por auditores externos (Inmetro, CGCRE) |
   | **Reclamação de cliente** | Problema reportado pelo cliente |
   | **Análise crítica** | Identificada em reunião de análise crítica da gestão |

3. **Classificação**

   - **Tipo:** Corretiva (resolver problema existente) ou Preventiva (evitar problema potencial)
   - **Severidade:** Menor / Maior / Crítica
   - **Categoria:** Método / Equipamento / Pessoal / Procedimento / Ambiente / Outro

4. **Responsável e prazo**

   - **Responsável:** Pessoa designada para conduzir a CAPA
   - **Data limite:** Prazo para conclusão

5. **Salvar**

   O sistema gera automaticamente um número único (ex: CAPA-2026-0001).

</Steps>

## Fluxo de Status

```
Aberta → Investigação → Implementação → Verificação → Encerrada
```

| Status | Descrição | Quem atua |
| :--- | :--- | :--- |
| **Aberta** | CAPA registrada | Responsável designado |
| **Investigação** | Análise de causa raiz em andamento | Responsável |
| **Implementação** | Plano de ação sendo executado | Responsável |
| **Verificação** | Verificação de eficácia | Administrador, Proprietário |
| **Encerrada** | CAPA encerrada com eficácia confirmada | Administrador, Proprietário |

## Análise de Causa Raiz

Durante a fase de **Investigação**, o responsável deve documentar a análise de causa raiz. O sistema suporta os seguintes métodos:

| Método | Descrição |
| :--- | :--- |
| **5 Porquês** | Perguntar "por quê?" repetidamente até chegar à causa fundamental |
| **Diagrama de Ishikawa** | Diagrama espinha de peixe (causas categorizadas: mão de obra, método, máquina, material, meio ambiente, medição) |
| **Análise de Pareto** | Identificar as poucas causas que geram a maioria dos problemas |
| **Outro** | Método livre |

O campo **Análise de Causa Raiz** registra a descrição completa da investigação.

## Plano de Ação

Após identificar a causa raiz, o responsável registra:

- **Plano de ação:** Ações corretivas específicas a serem executadas
- **Medidas preventivas:** Ações para evitar recorrência

## Implementação

Ao executar o plano de ação:

<Steps>

1. Registre a **evidência de implementação** (o que foi feito, documentos de suporte)
2. Clique em **Registrar Implementação**
3. O status muda para **Implementação** → **Verificação**
4. Data da implementação é registrada automaticamente

</Steps>

## Verificação de Eficácia

A etapa final é a verificação, realizada pelo responsável técnico (Administrador ou Proprietário):

<Steps>

1. Avalie se a ação corretiva foi eficaz
2. Registre **notas de verificação** com justificativa
3. Confirme a **eficácia** (sim ou não)
4. Se eficaz → clique em **Encerrar CAPA** → status **Encerrada**
5. Se não eficaz → uma nova CAPA pode ser necessária

</Steps>

<Aside type="caution">
  Somente administradores ou proprietários podem verificar eficácia e encerrar CAPAs. Isso garante supervisão gerencial conforme ISO/IEC 17025.
</Aside>

## Métricas de Qualidade

O painel de CAPAs fornece métricas para análise crítica da gestão:

- **Taxa de eficácia:** Percentual de CAPAs encerradas com eficácia confirmada
- **CAPAs atrasadas:** Ações que ultrapassaram o prazo — requerem atenção imediata
- **Distribuição por categoria:** Identifica áreas recorrentes de problemas (ex: se a maioria é "Equipamento", pode indicar necessidade de investimento em manutenção)
- **Distribuição por severidade:** Monitorar se problemas críticos estão sendo tratados com prioridade
