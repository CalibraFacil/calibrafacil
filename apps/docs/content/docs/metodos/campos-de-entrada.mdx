---
title: Campos de Entrada
description: Tipos de campos disponíveis no Construtor de Métodos — número, texto, seleção e tabela — com exemplos práticos.
---


Os **campos de entrada** definem quais dados o técnico coletará durante a calibração. Cada campo possui um **rótulo** (exibido no formulário) e uma **chave** (variável usada nas fórmulas).

## Tipos de Campo

### Número

O tipo mais comum. Aceita valores numéricos com unidade e casas decimais opcionais.

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Rótulo | Sim | Nome exibido no formulário (ex: "Leitura do Padrão") |
| Chave | Sim | Nome da variável nas fórmulas (ex: `leitura_padrao`) |
| Unidade | Não | Unidade de medida (ex: mm, °C, kg, Pa) |
| Obrigatório | Não | Se o campo deve ser preenchido |
| Valor padrão | Não | Valor pré-preenchido |

**Exemplo de uso em fórmula:** `leitura_padrao - leitura_instrumento`

### Texto

Aceita texto livre. Útil para observações, identificação de instrumentos ou condições não numéricas.

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Rótulo | Sim | Nome exibido no formulário |
| Chave | Sim | Nome da variável |
| Unidade | Não | Unidade exibida ao lado do campo |
| Obrigatório | Não | Se o campo deve ser preenchido |
| Valor padrão | Não | Texto pré-preenchido |

<Aside type="note">
  Campos de texto não podem ser usados em fórmulas matemáticas. Use-os apenas para informações descritivas.
</Aside>

### Seleção

Lista suspensa com opções predefinidas. Útil para parâmetros discretos como faixas de medição ou tipos de instrumento.

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Rótulo | Sim | Nome exibido no formulário |
| Chave | Sim | Nome da variável |
| Opções | Sim | Lista de valores possíveis (mínimo 1) |
| Obrigatório | Não | Se o campo deve ser preenchido |

**Exemplo:** Um campo "Faixa" com opções: `0-100`, `100-500`, `500-1000`.

### Tabela

Permite múltiplas linhas de dados — ideal para séries de leituras repetidas. Cada coluna da tabela é configurada individualmente.

| Propriedade | Obrigatório | Descrição |
| :--- | :--- | :--- |
| Rótulo | Sim | Nome da tabela no formulário |
| Chave | Sim | Nome da variável da tabela |
| Colunas | Sim | Definição das colunas (mínimo 1) |
| Obrigatório | Não | Se a tabela deve conter dados |

Cada **coluna** possui:

| Propriedade | Descrição |
| :--- | :--- |
| Rótulo | Nome exibido no cabeçalho |
| Chave | Identificador da coluna |
| Tipo | `number` (numérico) ou `text` (texto) |
| Unidade | Unidade exibida no cabeçalho (opcional) |

**Acesso aos dados da tabela em fórmulas:**

Para uma tabela com chave `leituras` e coluna com chave `valor`:

```
mean(leituras_valor)     // Média dos valores da coluna
std(leituras_valor)      // Desvio padrão da coluna
sum(leituras_valor)      // Soma dos valores da coluna
min(leituras_valor)      // Menor valor da coluna
max(leituras_valor)      // Maior valor da coluna
leituras_valor_count     // Quantidade de linhas
leituras_valor_0         // Primeiro valor (índice 0)
leituras_valor_1         // Segundo valor (índice 1)
```

<Aside type="tip">
  Tabelas são a forma recomendada para séries de leituras repetidas. Funções estatísticas como `mean` e `std` ficam disponíveis automaticamente para colunas numéricas.
</Aside>

## Regras para Chaves de Campo

A **chave** (variável) de cada campo deve seguir estas regras:

1. **Começar com uma letra** — não pode iniciar com número ou caractere especial
2. **Conter apenas letras, números e underscore** (`_`)
3. **Ser única** dentro do método — não pode repetir chaves de outros campos ou fórmulas
4. **Não usar nomes reservados** — funções matemáticas (`abs`, `sqrt`, `mean`, `std`, etc.), constantes (`pi`, `e`) e variáveis do sistema de incerteza (`u_typeA`, `u_typeB`, `u_combined`, `U_expanded`, `k`, `n`) não podem ser usadas como chave

<Aside type="caution">
  O rótulo é convertido automaticamente em chave (slugificado). Exemplo: "Leitura do Padrão" → `leitura_do_padrao`. Você pode editar a chave manualmente a qualquer momento.
</Aside>
