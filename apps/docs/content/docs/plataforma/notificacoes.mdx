title: Notificações
description: Eventos notificáveis do laboratório, canais disponíveis e preferências de entrega.
---

As preferências de notificação ficam em **Configurações → Notificações** (`/dashboard/settings/notifications`). Cada usuário controla seus próprios canais por tipo de evento.

## Eventos Notificáveis

| Evento | Canais |
| :--- | :--- |
| OS submetida para revisão | In-app, Email |
| OS aprovada | In-app, Email |
| OS rejeitada | In-app, Email |
| OS atribuída | In-app, Email |
| Certificado pronto | In-app, Email |
| Certificado retificado | In-app, Email |
| Ativo para recalibração | In-app, Email |
| Padrão expirando | In-app, Email |
| Não conformidade criada | In-app, Email |
| NC escalada para CAPA | In-app, Email |
| Competência solicitada | In-app, Email |
| Competência aprovada | In-app, Email |
| Competência expirando | In-app, Email |
| Competência expirada | In-app, Email |

## Preferências Adicionais

- **Notificar ações próprias** — receber notificação das próprias ações (padrão: desligado).
- **Resumo por email** — nenhum, diário ou semanal.
