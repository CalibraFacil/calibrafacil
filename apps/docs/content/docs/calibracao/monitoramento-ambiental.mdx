---
title: Monitoramento Ambiental
description: Configuração de limites ambientais, registro de condições durante a calibração e conformidade com a ISO/IEC 17025:2017.
---


O módulo de **Monitoramento Ambiental** permite configurar limites aceitáveis de temperatura, umidade e pressão atmosférica, registrar as condições ambientais durante cada calibração e garantir rastreabilidade conforme a **ISO/IEC 17025:2017 — cláusula 6.3** (Instalações e condições ambientais).

## Grandezas Monitoradas

| Grandeza | Unidade | Exemplo de Limites |
| :--- | :--- | :--- |
| **Temperatura** | °C | 18 – 25 °C |
| **Umidade Relativa** | %RH | 30 – 70 %RH |
| **Pressão Atmosférica** | hPa | 960 – 1060 hPa |

Todas as grandezas são opcionais. Campos deixados em branco não serão verificados durante a execução.

## Configuração de Limites

Acesse **Painel → Configurações → Condições Ambientais** (`/dashboard/settings/environment`).

### Limites Padrão (Organização)

Os limites padrão se aplicam a **todas as calibrações** da organização, independentemente do tipo de instrumento.

<Steps>

1. Clique em **Configurar limites padrão** (ou **Editar limites padrão** se já existirem)
2. Preencha os valores mínimo e máximo desejados para cada grandeza
3. Clique em **Salvar**

</Steps>

### Limites por Tipo de Equipamento

Para tipos de instrumento com requisitos ambientais distintos (ex: balanças com faixa de temperatura mais restrita), crie **exceções** que sobrescrevem os limites padrão.

<Steps>

1. Na seção **Limites por Tipo de Equipamento**, clique em **Adicionar exceção**
2. Selecione o tipo de equipamento na lista
3. Preencha os limites específicos para esse tipo
4. Clique em **Salvar**

</Steps>

### Hierarquia de Resolução

Quando o técnico executa uma calibração, o sistema determina os limites efetivos na seguinte ordem:

1. **Limites do tipo de equipamento** — se existir uma exceção configurada para o tipo do instrumento sendo calibrado
2. **Limites padrão da organização** — caso contrário

<Aside type="note">
  Se nenhum limite estiver configurado (nem padrão, nem por tipo), as calibrações serão realizadas sem verificação de condições ambientais.
</Aside>

## Registro durante a Execução

Na [tela de execução da OS](/calibracao/ordens-de-calibracao/execucao), uma seção de **Condições Ambientais** permite ao técnico registrar as condições no momento da calibração:

- **Temperatura (°C)** — temperatura ambiente no local da medição
- **Umidade Relativa (%RH)** — umidade relativa do ar
- **Pressão Atmosférica (hPa)** — pressão barométrica local

O sistema valida os valores em tempo real contra os limites configurados:

| Indicador | Significado |
| :--- | :--- |
| Sem alerta | Valor dentro dos limites |
| Aviso (amarelo) | Valor fora dos limites configurados |

<Aside type="tip">
  Os valores ambientais ficam disponíveis como variáveis nas fórmulas do método: `env_temperature`, `env_humidity` e `env_pressure`. Isso permite que cálculos de incerteza levem em conta as condições ambientais. Consulte [Fórmulas — Variáveis Ambientais](/metodos/formulas#variáveis-ambientais).
</Aside>

## Snapshot Ambiental

Ao submeter a OS para revisão, o sistema cria um **snapshot** das condições ambientais contendo:

- Valores registrados pelo técnico (temperatura, umidade, pressão)
- Limites efetivos no momento do registro
- Indicação se as condições estavam dentro dos limites
- Identificação do responsável e data/hora do registro

Esse snapshot é **imutável** — alterações posteriores nos limites configurados não afetam registros já realizados, garantindo rastreabilidade completa.

## Aprovação com Condições Fora dos Limites

Se as condições ambientais estiverem **fora dos limites** configurados, o fluxo de aprovação exige uma etapa adicional:

<Steps>

1. O revisor identifica o alerta de condições fora dos limites na tela de revisão
2. Ao aprovar, o sistema solicita uma **justificativa técnica** obrigatória
3. O revisor preenche a justificativa explicando por que o resultado é válido apesar das condições
4. A justificativa é registrada no snapshot e fica disponível para auditorias

</Steps>

<Aside type="caution">
  A aprovação é **bloqueada** até que a justificativa seja preenchida. Isso garante que nenhuma calibração com condições fora dos limites seja aprovada sem análise técnica documentada.
</Aside>

## Conformidade ISO/IEC 17025:2017

O módulo de monitoramento ambiental atende aos seguintes requisitos normativos:

| Cláusula | Requisito | Como o CalibraFácil atende |
| :--- | :--- | :--- |
| **6.3.2** | Requisitos de condições ambientais documentados | Limites configuráveis por organização, unidade e tipo de ativo |
| **6.3.3** | Monitorar, controlar e registrar condições ambientais | Registro obrigatório das condições durante cada calibração e validação automática contra os limites |
| **7.7** | Garantia da validade dos resultados | Snapshot imutável das condições e bloqueio/justificativa quando fora dos limites |
| **8.4** | Controle de registros | Trilha de auditoria com responsável, data/hora e justificativas |

Para mais detalhes sobre conformidade, consulte [Conformidade ISO 17025](/conceitos/iso-17025).

## Permissões

| Ação | Papéis permitidos |
| :--- | :--- |
| Configurar limites (padrão e exceções) | Administrador, Proprietário |
| Registrar condições durante execução | Operador, Técnico, Administrador, Proprietário |
| Aprovar com justificativa ambiental | Administrador, Proprietário |
